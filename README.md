## 🚀 Featured Builds

<table>
<tr>
<td width="50%" valign="top">

### 🎙️ Realtime Voice Agent + Avatar + RAG
**Voice AI with a live avatar**

Real-time voice agent using Deepgram Nova-3 for speech-to-text, Cartesia Sonic 3 for speech, GPT-4.1 for reasoning and a Tavus avatar. A FAISS knowledge base ingests PDFs and uses cross-encoder reranking. Next.js 15 frontend.

`LiveKit` `Deepgram` `Cartesia` `Tavus` `FAISS` `Next.js`

[▶️ Watch Demo](https://www.loom.com/share/6698ddb1982c40828377ed9a8d113dfc) · [🔗 Repo](https://github.com/hamzasaleem22/Realtime-VoiceAgent-Avatar-Rag)

</td>
<td width="50%" valign="top">

### 📦 BERTO's RAG Pipeline
**RAG for a multilingual product catalog**

CPU-first RAG pipeline over a 120-page catalog. It extracts SKU specs, prices and dimensions from dense tables, using Docling parsing, tiered chunking, BGE-M3 ONNX embeddings, hybrid BM25 and dense retrieval, and cross-encoder reranking.

`Python` `Docling` `FAISS` `LanceDB` `BM25` `FastAPI`

[🔗 Repo](https://github.com/hamzasaleem22/bertos-company-rag-monorepo)

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🚛 AI Tow Truck Dispatch
**Voice dispatch with live tracking**

An AI voice agent (n8n and Twilio) answers calls, collects customer details and dispatches the nearest driver by GPS proximity. Includes live tracking, an admin dashboard with a map, a driver PWA and Google Sheets sync.

`n8n` `Twilio` `Pusher` `Neon` `Google Maps` `PWA`

[🔗 Repo](https://github.com/hamzasaleem22/Tow_Truck)

</td>
<td width="50%" valign="top">

### 🔍 RAG: Microsoft Annual Report
**Full-stack RAG over a financial report**

RAG chatbot over Microsoft's 2025 Annual Report. FastAPI and FAISS with MMR retrieval and cross-encoder reranking. TanStack React chat UI with source citations and query caching.

`FastAPI` `FAISS` `MMR` `TanStack` `TypeScript`

[🌐 Live](https://rag-pipeline.lovable.app) · [🔗 Repo](https://github.com/hamzasaleem22/fullstack-microsoft-report-rag)

</td>
